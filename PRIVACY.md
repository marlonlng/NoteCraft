# NoteCraft Privacy Policy

Last updated: October 23, 2026

NoteCraft is a text editor for macOS. It is built so that it doesn't collect any personal data.

## What data NoteCraft handles

- **Your documents** are read and saved only on your Mac, in the places you choose.
- **Unsaved documents** are kept locally by macOS so that NoteCraft can restore them at the next launch.
- **Settings** such as font size or theme are stored locally in the macOS user defaults.
- **Opened folders** are stored locally as security-scoped bookmarks so that NoteCraft can show the folder again at the next launch. The same applies to folders you allow for images in the Markdown preview.
- **Images from the internet** in the Markdown preview load only after you allow it for a document or in the settings. NoteCraft then requests the image directly from the server named in the document. Like every web request, this tells that server your IP address. NoteCraft remembers locally for which documents you allowed it.

## What NoteCraft doesn't do

- It doesn't send any data to the developer or to third parties.
- It contains no analytics, advertising or tracking tools.
- It has no user accounts. It connects to the internet only to load images in the Markdown preview, and only when you allow it.

## Sharing

When you use **Share**, NoteCraft hands the document to the macOS service you choose. That service's terms apply from then on.

## Contact

NoteCraft is developed by Marlon Lange. For questions about privacy, open an issue at <https://github.com/marlonlng/NoteCraft/issues>.

# Datenschutzerklärung für NoteCraft

Stand: 23. Oktober 2026

NoteCraft ist ein Texteditor für macOS. Er ist so gebaut, dass keine personenbezogenen Daten erhoben werden.

## Welche Daten verarbeitet NoteCraft?

- **Deine Dokumente** werden ausschließlich lokal auf deinem Mac gelesen und gesichert, an den Orten, die du selbst auswählst.
- **Ungesicherte Dokumente** bewahrt macOS lokal auf, damit NoteCraft sie beim nächsten Start wiederherstellen kann.
- **Einstellungen** wie Schriftgröße oder Farbschema werden lokal in den Benutzereinstellungen von macOS gespeichert.
- **Geöffnete Ordner** werden lokal als sicheres Lesezeichen (Security-Scoped Bookmark) gespeichert, damit NoteCraft den Ordner beim nächsten Start wieder anzeigen kann. Das gilt auch für Ordner, die du für Bilder in der Markdown-Vorschau erlaubst.
- **Bilder aus dem Internet** in der Markdown-Vorschau werden erst geladen, wenn du es für ein Dokument oder in den Einstellungen erlaubst. NoteCraft ruft das Bild dann direkt von dem Server ab, der im Dokument steht. Wie bei jedem Abruf aus dem Internet erfährt dieser Server dabei deine IP-Adresse. Für welche Dokumente du es erlaubt hast, merkt sich NoteCraft lokal.

## Was NoteCraft nicht tut

- Keine Übertragung von Daten an den Entwickler oder an Dritte
- Keine Analyse-, Werbe- oder Tracking-Werkzeuge
- Kein Benutzerkonto; eine Verbindung ins Internet nur zum Laden von Bildern in der Markdown-Vorschau und nur, wenn du es erlaubst

## Teilen

Wenn du **Teilen** verwendest, übergibt NoteCraft das Dokument an den von dir gewählten macOS-Dienst. Für die weitere Verarbeitung gelten dann die Bedingungen dieses Dienstes.

## Kontakt

NoteCraft wird von Marlon Lange entwickelt. Fragen zum Datenschutz stellst du als Issue unter <https://github.com/marlonlng/NoteCraft/issues>.
