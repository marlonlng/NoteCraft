# Security Policy

## Reporting a vulnerability

Please don't report security issues in public issues or pull requests. Use GitHub's private vulnerability reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include the NoteCraft version, your macOS version, the steps to reproduce the issue and its impact. You'll get an answer within a week.

## Supported versions

Security fixes are made for the latest version available in the Mac App Store.
